## 1. Objective

Create a reproducible repository in which `ds0` and `ds1` build byte-for-byte, the oracle computes every exact-answer and planted-cause truth and every declared signature from emitted events alone, the generator's construction ledger agrees with the oracle, planted faults F1–F5 are injectable and isolated, and an independent checker (`make gate-K1`) proves all of this with negative controls.

## 4. Gate

`make gate-K1` must pass with every criterion K1-C1…K1-C8 and every negative control listed in contract §14 K1. The checker MUST force reconstruction (delete outputs and caches it reads, rebuild in fresh subprocesses into empty directories). A checker that cannot fail is not evidence: run the negative controls and confirm each fails exactly its criterion.
